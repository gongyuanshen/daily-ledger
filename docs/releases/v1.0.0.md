# v1.0.0 — Daily Ledger · 日常记账

English | [简体中文](#简体中文)

Initial public preview for Windows and Android, published on 2026-10-12.

## Downloads

- `daily-ledger-1.0.0-android-debug.apk`: installable, debug-signed Android development build. Requires Android 7.0 / API 24 or newer, arm64-v8a or x86_64, and Android System WebView.
- `daily-ledger-1.0.0-windows-source.zip`: Windows source package. Requires Python with Tkinter, SQLite 3.37+, and CustomTkinter 6.0.0. Verified with Python 3.14.4. Extract it, install `requirements.txt`, and run `python app.py` or double-click `启动记账.cmd`.
- `SHA256SUMS.txt`: checksums for the APK and Windows ZIP.

Both source projects are included in the repository. All published guides and release descriptions present English first and Chinese second. The current app interfaces use Chinese.

## Included features

Expense CRUD and filters; exact RMB amounts up to six decimal places; annual calendar and daily/monthly/yearly totals; category statistics; monthly budgets; product prices and quantity calculations; filtered CSV export; complete SQLite backup and restore.

Each version stores data locally. Move data between versions by exporting a SQLite backup and restoring it on the other device. Restore replaces the complete ledger, budgets, and products. There is no automatic synchronization.

## Current limits

- Android is a debug build; Android 16/17 device acceptance is pending. Static APK checks and Python/browser tests do not establish device compatibility.
- Windows is distributed as source and requires Python. A standalone Windows EXE is not included.
- Restore requires the current ledger to be readable. It cannot repair a current database that is already too damaged to open.
- Android draft state covers page refresh, without guaranteeing recovery after process termination. Export an accessible backup before uninstalling or changing phones.

Personal databases, import records, backups, logs, local toolchains, and signing keys are excluded from the source and release downloads.

### 下载文件

- `daily-ledger-1.0.0-android-debug.apk`：可安装的 debug 签名安卓开发版，需要 Android 7.0 / API 24 及以上、arm64-v8a 或 x86_64，以及 Android System WebView。

### 已包含功能

支出新增、修改、删除与筛选；最多六位小数的人民币精确金额；年度日历与每日、每月、全年汇总；分类统计；月度预算；商品单价与数量计算；按筛选导出 CSV；完整 SQLite 备份和恢复。

两个版本分别在本地保存数据。跨设备迁移时导出 SQLite 备份，再到另一端恢复。恢复会整体替换账本、预算和商品，不会自动同步。

### 当前限制

- 安卓包是 debug 开发版，Android 16/17 真机验收尚未完成。APK 静态检查、Python 测试和浏览器验证不能证明真机兼容。
- Windows 使用源码形式分发，需要 Python，本版本未提供独立 EXE。
- 恢复要求当前账本可正常读取，无法修复已经损坏到打不开的当前数据库。
- 安卓草稿状态覆盖页面刷新，不保证进程结束后的恢复。卸载或换机前请主动导出可访问的备份。

源码和下载包均排除个人数据库、导入记录、备份、日志、本地工具链和签名密钥。
